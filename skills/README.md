# Skill catalog

Each directory is a complete portable bundle. Read its `SKILL.md` and only the references routed from it for the current
task. Use the [installation guide](../docs/installation.md) to make the workflows available in an application.

| Skill                            | Workflow                                           |
| -------------------------------- | -------------------------------------------------- |
| [yii3-application][application]  | Discover and change a real Yii3 application        |
| [yii3-container-integration][di] | Integrate configuration, DI, and runtime wiring    |
| [yii3-package][package]          | Develop, review, test, and document a Yii3 package |

[application]: yii3-application/SKILL.md
[di]: yii3-container-integration/SKILL.md
[package]: yii3-package/SKILL.md

Package-specific workflows remain in their owning repositories. Discover them from installed Composer package metadata;
do not assume this catalog mirrors every Yii3 package.
